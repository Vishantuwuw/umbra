## Download &amp; install

1. Go to the [**latest release**](https://github.com/coldvini/umbra/releases/latest) and download the right file for your Mac:
   - **Apple Silicon** (M1/M2/M3/M4) → `Umbra-*-arm64.dmg`
   - **Intel Mac** → `Umbra-*-x64.dmg`
2. Open the `.dmg` and drag **Umbra** into **Applications**.
3. Umbra isn't notarized by Apple, so the first time: open it once, then go to **System Settings → Privacy &amp; Security** and click **Open Anyway**. (Or run `xattr -cr /Applications/Umbra.app` in Terminal.)
4. Umbra's welcome screen sets everything up — pick what you want (Steam is on by default) and click **Install**.

Then drop any `.exe` onto the window, or open **Get Apps** for one-click Steam, Epic, GOG and more.
